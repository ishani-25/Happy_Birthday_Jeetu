# Birthday surprise for Jeet ♡

This is a mobile-friendly romantic birthday website personalized with your photos and the nicknames Jeet, Jeetu, Jeetli, Lalu and Chaku.

## Preview
Extract the ZIP and open `index.html` in a browser. Keep the `photos` folder beside it.

## Publish a public link for free using GitHub Pages
1. Sign in at https://github.com/
2. Create a **public** repository named `birthday-surprise`.
3. Upload `index.html` and the entire `photos` folder to the repository root (not just the HTML file).
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch `main` and folder `/(root)`, then click **Save**.
7. Wait for the deployment to finish. The public URL will look like `https://YOUR-USERNAME.github.io/birthday-surprise/`. GitHub Pages will show the exact link in Settings → Pages.

## Personalize more
Open `index.html` in a text editor to edit the letter or captions. The photos are included in the `photos` folder. The site does not collect data or require a login.

## Privacy
A public website can be visited by anyone who gets the link and may be indexed or shared. Only publish photos and words you are comfortable making public. If you'd prefer not to make the photos public, use a private sharing option instead.
